# 역할표

> **확인일: 2026-10-14.** 이 파일의 원칙(세 축, 고르는 법)은 거의 안 바뀐다. 역할표의 모델명·추론 강도는 벤더 파일(`claude-cli.md`, `codex-cli.md`)이 바뀔 때 함께 고친다.

## 축이 세 개다

| 축 | 무엇을 정하나 | 기본값으로 둬도 되나 |
|---|---|---|
| **모델** | 아는 것의 양 (가중치) | 난이도에 맞으면 |
| **추론** | 꼼꼼함 — 파일을 몇 개 읽고 테스트를 돌리는지 | claude는 대부분 예. codex는 **아니오** — 모델마다 기본값이 달라서 명시한다 |
| **권한** | 읽기만 / 편집까지, 그리고 승인 프롬프트를 **누가 답하는지** | **아니오 — 안 정하면 pane이 멈춘다** |

**어느 축을 올릴지 고르는 법** (Anthropic 공식 가이드):

```
맥락은 다 줬는데 틀렸다        →  모델을 올린다  (아는 게 부족)
파일을 빼먹거나 테스트를 안 돌렸다  →  추론을 올린다  (꼼꼼함이 부족)
둘 다 아니다                  →  기본값. 건드리지 않는다
```

OpenAI 쪽 원칙도 같은 방향이다 — "필요한 결과를 내는 **가장 낮은** 추론 강도를 쓰고, 계획·분석·검증이 더 필요할 때만 올려라."

**반대 방향 주의**: 어려운 작업에 작은 모델을 쓰면 오히려 비싸진다. 단계를 더 밟고 재시도하기 때문이다. 규칙은 "무조건 아껴라"가 아니라 **"난이도에 맞춰라"** 다.

## 역할표

| 역할 | claude | codex | 권한 |
|---|---|---|---|
| 탐색·검색 | `haiku` / `low` | `gpt-6-luna` / `high` | 읽기 전용 |
| 리뷰 | `sonnet` / `high` | `gpt-6.1-sol` / `high` | 읽기 전용 |
| 구현 | `sonnet` / 기본(`medium`) | `gpt-6.1-sol` / `medium` | 편집 · 자동 검토 |
| 어려운 버그·아키텍처 | `opus` / `high`~`xhigh` | `gpt-6.1-sol` / `high` | 편집 · 자동 검토 |
| 장시간 다단계 | `fable` (없으면 `best`) / 기본 | `gpt-6.1-sol` / `high` | 편집 · 자동 검토 |
| 최고 난도 종단간 작업 | `opus` / `high`~`xhigh` | `gpt-6-astra` / `low`에서 시작 | 편집 · 자동 검토 |
| 테스트·빌드·로그 | — | — | **에이전트를 띄우지 않는다** |

마지막 줄이 중요하다. 명령 하나 돌리고 출력을 읽는 일에는 에이전트가 필요 없다 → `herdr pane run`.

**"편집 · 자동 검토"가 무슨 뜻인가.** 두 CLI 모두 승인 프롬프트를 모델이 대신 받는 모드가 있다 — claude는 분류기(classifier), codex는 리뷰어 에이전트. 편집이 필요한 역할은 이걸 켠다. 안 켜면 파일 편집만 통과하고 bash 명령마다 pane이 `blocked`로 멈춘다. 각 모드의 플래그는 벤더 파일에 있다.

**"읽기 전용"이 무슨 뜻인가.** claude는 `plan` 모드가 아니다 — `auto` 모드에 편집 도구를 차단해서 띄운다. plan은 웹 조회마다 멈추고, 끝에 계획이 승인되면 편집이 풀린다 (2026-10-14 사고). 차단이 bash까지 닿지는 않으므로 프롬프트에 "파일 수정·외부 게시 금지"를 적는다 (`claude-cli.md`의 실측 표). codex는 `-s read-only -a never`. 정확한 플래그는 벤더 파일에 있다.

**장시간 다단계에 codex는 astra가 아니라 6.1-sol인 이유.** 공식 문서가 6.1-sol을 "Astra에 가까운 성능을 더 싸게, 반복적인 장시간 작업에 권장"으로 두기 때문이다. 한 번에 끝내야 하는 가장 어려운 문제는 astra, 오래 도는 일은 6.1-sol.

**Astra를 쓰는 때.** 코드·앱·리서치를 오가며 여러 단계의 판단을 끝까지 유지해야 하는 최고 난도 작업이다. 실행 시간이 긴 것만으로 고르지 않는다. 공식 모델 안내는 Astra의 추론을 `low`에서 시작해 필요할 때 올리라고 권한다.

## 추론 단계는 벤더마다 다르다

claude는 5단계(`low`~`max`). codex는 모델에 따라 5단계 또는 6단계(`low`~`max`, 그 위 `ultra`)이고, luna 계열에는 `ultra`가 없다. codex의 `ultra`는 "최대 추론 + 자동 위임(서브에이전트)" 모드라 claude의 `max`와 같은 것이 아니다. **같은 이름으로 묶지 말 것.**

기본값도 다르다. claude는 현재 별칭이 가리키는 5.5 세대가 전부 `medium`. codex는 `gpt-6-astra`·`gpt-6.1-sol`이 `low`, 나머지가 `medium`. 그래서 codex는 추론 강도를 항상 명시한다 — 안 적으면 가장 큰 모델이 가장 얕게 생각한다.
