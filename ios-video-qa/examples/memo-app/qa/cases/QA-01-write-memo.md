# QA-01 메모 쓰기

빈 목록에서 새 메모를 쓰고 저장하면 목록에 그 메모가 보인다.

- 명세: 없음
- 준비: 빈 목록
- 실행: 자동
- 입력: 화면 키보드
- 조건: 기본
- 화면: 목록, 편집

| # | 행동 | 자동 확인 | 눈으로 확인 |
|---|---|---|---|
| 1 | '새 메모' 탭 | 편집 화면 제목 '새 메모' | 키보드가 올라오며 입력칸이 가려지지 않음 |
| 2 | "장보기" 입력 | 입력칸에 "장보기" · '저장' 버튼이 키보드 위에 보임 | |
| 3 | '저장' 탭 | 목록에 "장보기" · 메모 수가 1 늘어남 | 목록 맨 위에 새 메모 |

## 메모
- 저장 뒤 앱을 다시 열어도 남는지는 QA-02에서 본다(상태 재확인 단계).
