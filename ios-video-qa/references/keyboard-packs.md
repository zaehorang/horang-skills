# 자판 팩과 기기 가정

## 자판 팩 인터페이스

`scripts/lib/keyboard/<언어>.py`, `qa.config`의 `QA_INPUT_LANG=<언어>`로 고른다. 지금 있는 팩: `ko`(한국어 두벌식, 기기에서 확인함), `en`(US QWERTY, 기기에서 확인하지 않음).
팩은 명령 셋을 같은 형식으로 낸다.

| 명령 | 출력 | 쓰는 곳 |
|---|---|---|
| `<팩> "<글자>"` | 하드웨어 키보드로 보낼 키 문자열 | 블루투스 키보드 각본(`ui_type`) |
| `<팩> --keys "<글자>"` | 화면 키보드에서 누를 키 label, 한 줄에 하나(공백은 `" "`) | 화면 키보드 각본 |
| `<팩> --labels` | zsh 변수 정의(아래 전부) | 엔진이 시작할 때 eval |

| 변수 | 뜻 |
|---|---|
| `KB_SHIFTED` | shift 뒤에만 나오는 키(글자들) |
| `KB_PROBE_KEYS` | 이 키가 보이면 이 언어 자판이 떠 있다(공백으로 나눔) |
| `KB_GLOBE_LABEL` | 언어 전환 키의 label |
| `KB_OTHER_LANG_LABEL` | 다른 언어 자판이 떠 있을 때 전환 키의 label |
| `KB_DELETE_LABEL` | 지우기 키 label |
| `KB_RETURN_ID` `KB_DELETE_ID` `KB_SHIFT_ID` `KB_MORE_ID` `KB_SPACE_ID` | 특수 키의 식별자 |
| `KB_ASSISTANT_ID` | 예상 단어 막대 식별자(키보드 윗변 판정에 씀) |
| `KB_MORE_TO_LETTERS` | 숫자·기호 자판에서 'more' 키의 label(공백으로 나눔) |
| `KB_LANG_NAME` | 언어 전환 키를 길게 눌렀을 때 목록에 보이는 이 자판의 이름 |

label 일부(전환 키, 자판 이름)는 입력 언어가 아니라 **시뮬레이터의 UI 언어**를 따른다. 팩은 한 UI 언어 기준으로 쓰고, 다르면 팩을 하나 더 만든다.
새 팩을 만들면 `qa test`가 변수 목록을 확인한다. 기기에서 한 번 돌려 본 뒤에 "확인함"으로 적는다.

## 화면 키보드가 뜨는 조건

Simulator.app 창이 있고 시뮬레이터 전역 설정 "하드웨어 키보드 연결"이 꺼져 있어야 한다. 실행이 잠금(`/tmp/ios-video-qa.lock.d`)을 잡고 원래 값을 적은 뒤 끄고, 끝날 때(실패·중단에도) 되돌린다. 그래서 Mac(사용자)당 한 번에 한 실행만 된다.
하드웨어 키 입력을 보낸 부팅에서는 화면 키보드가 다시 뜨지 않아, 그 뒤 화면 키보드 각본 전에 재부팅한다.

## 기기·화면 가정

- 세로 iPhone 화면. `ui_swipe`는 화면 높이의 0.74 → 0.29(위로), 화면 키보드 키는 화면 높이 0.45 아래에서 찾는다(`KB_LOWER_RATIO`). iPad·가로 화면은 지원하지 않는다.
- 조건의 기기는 이름으로 찾는다(사용 가능한 iOS 런타임 중 마지막). 템플릿의 기기 이름은 예시이고, `qa init`은 이 Mac에 있는 iPhone을 채운다. `qa doctor`가 이름을 확인한다.
- 숫자 키패드에는 예상 단어 막대가 없어 키보드 윗변을 첫 키 줄로 잰다(실제 배경보다 조금 아래).
