# 타이포와 정보 예산

1280×720 고정 캔버스 기준. 두 표는 **한 몸이다.** 글자를 키우면 넣을 수 있는 내용이 줄고,
내용을 늘리려면 글자를 줄여야 한다. 글자를 줄이는 쪽은 선택지가 아니다.

## 타이포 스케일

발표 가독성은 화면 해상도가 아니라 **슬라이드 높이 대비 글자 비율**이 결정한다.
시야각은 해상도와 무관하게 고정이기 때문이다.

| 역할 | 토큰 | px | 720 대비 |
|---|---|---:|---:|
| 표지 제목 | `--fs-h1` | 72 | 10.0% |
| 슬라이드 제목 | `--fs-h2` | 50 | 6.9% |
| 카드 제목 | `--fs-h3` | 25 | 3.5% |
| 리드 문장 | `--fs-lead` | 24 | 3.3% |
| 본문 · 리스트 | `--fs-body` | 20 | 2.8% |
| 라벨 · 캡션 · 푸터 | `--fs-label` | 16 | 2.2% |

**절대 하한 2.0% = 14.4px.** 그 아래는 뒷줄에서 읽히지 않는다.
참고로 PowerPoint 기본 본문은 3.3%다. 2.8%는 정보 밀도를 감안한 타협선이다.

## 예산을 넘겼을 때

**글자를 줄이지 않는다. 내용을 줄인다.**

```
기존 지침·규칙·자동화·스킬을 못 찾아 다시 만듭니다   (23자)
→ 찾지 못해 다시 만든다                              (11자)
```

문장을 구절로 바꾸면 대개 절반이 된다. 나머지는 발표자가 말로 채운다.
슬라이드는 대본이 아니라 **청중이 3초 안에 결론을 잡게 돕는 근거**다.

## 이미지 안의 글자

2% 하한은 **생성 이미지와 화면 캡처 안의 글자에도 그대로 적용된다.** 검사기는 이걸
보지 못한다. 사람이 확인해야 한다.

제품 화면을 넣을 때 전체 화면을 그대로 쓰면 모든 컴포넌트가 작아져 아무것도 읽히지
않는다. **말하려는 관심 영역만 잘라 낸다.** 두 곳을 말해야 하면 두 번 잘라 나란히 둔다.

말풍선이 들어가는 상황 일러스트도 같다. 컷을 여럿으로 나누면 각 컷이 작아진다.
한 장면 + 말풍선 한두 개.

## 균등 나열의 함정

5개를 같은 크기로 놓으면 "다섯 개가 똑같이 중요하다"고 말하는 것이다.
우선순위가 있다면 패턴 E(1+4)를 쓴다. 레이아웃이 주장을 반박하게 두지 않는다.

강조(레드)는 **한 장에 한 곳.** 두 곳이면 이미 강조가 아니다.
