# 타이포와 정보 예산

1280×720 고정 캔버스 기준. 두 표는 **한 몸이다.** 글자를 키우면 넣을 수 있는 내용이 줄고,
내용을 늘리려면 글자를 줄여야 한다. 글자를 줄이는 쪽은 선택지가 아니다.

## 타이포 스케일

발표 가독성은 화면 해상도가 아니라 **슬라이드 높이 대비 글자 비율**이 결정한다.
시야각은 해상도와 무관하게 고정이기 때문이다.

| 역할 | 토큰 | px | 720 대비 |
|---|---|---:|---:|
| 표지 제목 | `--fs-h1` | 72 | 10.0% |
| 슬라이드 제목 | `--fs-h2` | 50 | 6.9% |
| 카드 제목 | `--fs-h3` | 25 | 3.5% |
| 리드 문장 | `--fs-lead` | 24 | 3.3% |
| 본문 · 리스트 | `--fs-body` | 20 | 2.8% |
| 라벨 · 캡션 · 푸터 | `--fs-label` | 16 | 2.2% |

**절대 하한 2.0% = 14.4px.** 그 아래는 뒷줄에서 읽히지 않는다.
내용이 적은 장은 `.content.roomy`(넘치면 중간 단계 `roomy-sm` — 23 · 18 · 28)로 올린다 — 카드 제목 32 · 리드 30 · 본문 26 · 라벨 20 (720 대비 4.4 · 4.2 · 3.6 · 2.8%). 아래 정보 예산은 기본 크기 기준이라, roomy 장은 그보다 적게 담는다.
기본 본문을 3.3%로 잡는 발표 형식도 있다. 2.8%는 정보 밀도를 감안한 타협선이다.

패턴 N은 가로로 긴 보고서 차트의 범위와 색을 유지해야 할 때 쓴다.
본문 폭은 1172px이며 1350×450 그림은 약 1172×391px로 표시된다.
제목·kicker·간격을 뺀 본문 높이 약 470px 안에 그림과 결론(34.8px),
출처(22.4px), 간격(20px)을 넣는다. 비율이 다른 그림은 `contain`으로 더 작게
맞춘다. 제목이나 결론이 두 줄이 되면 문장을 줄이거나 장을 나눈다.

## 구조도 예산

| 항목 | 한도 | 넘으면 |
|---|---:|---|
| 구조도 하나의 노드 | 9 | `dg-budget` 경고. 장을 나누거나 같은 그림을 2~3장에 걸쳐 단계별로 칠한다 |
| 레인 | 2 | 셋째 갈래는 다른 장으로 |
| 선 라벨 | 3 | 나머지는 말로 |
| 번호 | 5 | |
| 강조하는 되돌아감 선 | 1 | |
| 노드 이름 | 1줄 | 부연은 `<small>` 한 줄까지 |

노드 글자는 `--fs-body`(20px), 선 라벨·번호는 `--fs-label`(16px)이다. 레퍼런스 이미지처럼
괄호 안에 예시를 줄줄이 넣으면(“(PDF, Word, CSV, …)”) 하한 아래로 내려가기 쉽다. 빼고 말로 한다.

갈래 색(`--tone-a`/`--tone-b`)은 "어느 쪽인가"를 나타낸다. 강조와는 다른 축이다.
강조는 여전히 `.new` 노드나 결론 한 줄, 한 장에 한 곳이다.

## 예산을 넘겼을 때

**글자를 줄이지 않는다. 내용을 줄인다.**

```
기존 지침·규칙·자동화·스킬을 못 찾아 다시 만듭니다   (23자)
→ 찾지 못해 다시 만든다                              (11자)
```

문장을 구절로 바꾸면 대개 절반이 된다. 나머지는 발표자가 말로 채운다.
슬라이드는 대본이 아니라 **청중이 3초 안에 결론을 잡게 돕는 근거**다.

## 이미지 안의 글자

2% 하한은 **생성 이미지와 화면 캡처 안의 글자에도 그대로 적용된다.** 검사기는 이걸
보지 못한다. 사람이 확인해야 한다.

패턴 N의 1350px 원본을 1172px로 표시하면 배율은 약 0.87이다.
원본 글자 하한은 `14.4 × 1350 / 1172 ≈ 16.6px`다(계산값 16.587px).
예시 f2의 8pt 글자는 150dpi에서 약 16.67px이며, 표시 후 약 14.47px로
14.4px 하한을 넘는다. 높이 제한으로 배율이 더 작아지면 다시 계산한다.

제품 화면을 넣을 때 전체 화면을 그대로 쓰면 모든 컴포넌트가 작아져 아무것도 읽히지
않는다. **말하려는 관심 영역만 잘라 낸다.** 두 곳을 말해야 하면 두 번 잘라 나란히 둔다.

말풍선이 들어가는 상황 일러스트도 같다. 컷을 여럿으로 나누면 각 컷이 작아진다.
한 장면 + 말풍선 한두 개.

## 균등 나열의 함정

5개를 같은 크기로 놓으면 "다섯 개가 똑같이 중요하다"고 말하는 것이다.
우선순위가 있다면 패턴 E(1+4)를 쓴다. 레이아웃이 주장을 반박하게 두지 않는다.

강조(클레이)는 **한 장에 한 곳.** 두 곳이면 이미 강조가 아니다.
