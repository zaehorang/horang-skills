# deck-plan

원자료를 읽고 **장의 배열만** 설계한다. 슬라이드도 대본도 만들지 않는다.
사람이 배열을 승인한 뒤 `deck-narrate` 로 넘어간다.

FLOW 는 **뼈대**다. 장 안에서 무슨 말을 어떤 순서로 할지는 다음 단계 몫이다.
여기서 구체화하면 SCRIPT 와 겹치고, 겹친 두 문서는 반드시 어긋난다.

## 입력

사용자가 지정한 읽을 수 있는 파일만 근거로 삼는다. 내용을 지어내지 않는다.
자료가 부족하면 추측해서 채우지 말고 무엇이 없는지 말한다.

## 먼저 물을 것

작업 전에 아래를 확인한다. 이미 자료에 답이 있으면 다시 묻지 않는다.

| 항목 | 없으면 생기는 일 |
|---|---|
| 청중이 누구인가 | 심사자용과 팀 내부용은 정직성 표기 수준이 다르다 |
| 발표 시간 | 장수와 장당 분량이 정해지지 않는다 |
| 무엇을 결정·승인받고 싶은가 | 마지막 장이 흐려진다 |
| **함께 가는 산출물이 있는가** | 덱이 제출물의 몫까지 떠안고 나열식이 된다 |
| 렌더 타깃 — 브라우저 라이브인가 PDF인가 | 인쇄 CSS·애니메이션 판단이 뒤집힌다 |
| 구현 상태 3분류 | 발표 중에 사실이 아닌 말을 하게 된다 |

### 함께 가는 산출물

"이 발표와 함께 제출·공유되는 다른 자료가 있는가. 그리고 **무엇이 판단 대상인가.**"

이 답이 흐리면 시간 배분 논의 전체가 무효가 된다. 보고서·명세·설계 문서가 판단
대상이고 발표는 전달력만 본다면, 액터 표·스키마 전체 조감·에러 코드 목록은
**덱에 넣을수록 손해다.** 지루한 나열이 되고 정작 차별점을 말할 시간을 먹는다.

### 구현 상태 3분류

모든 주장을 다음으로 나눈다.

- `현재 확인됨` — 코드나 실행 결과로 확인한 것
- `제안` — 설계안이며 아직 구현되지 않은 것
- `예정` — 다음 단계 계획

## 산출물

선택한 작업 폴더에 `FLOW.md` 하나만 만든다.

```markdown
## 발표 목적
(한 문단. 청중이 무엇을 판단할 수 있게 되는가)

## 핵심 메시지
> (한 문장)

## 슬라이드 흐름
| 장 | 질문 | 핵심 주장 | 초 | 상태 |
|---:|---|---|---:|---|

## 산출물 분담
| 주제 | 덱 | 함께 가는 산출물 |
|---|---|---|

## 구현 상태 표기
(무엇이 확인됨/제안/예정인지)
```

각 장은 **질문 하나에만 답한다.** 한 장이 두 질문에 답하면 나눈다.
`핵심 주장` 은 한 줄이다. 근거와 전개는 적지 않는다 — `deck-narrate` 가 쓴다.

`산출물 분담` 은 함께 가는 자료가 있을 때만 만든다. 원칙은 비대칭이다.

- **덱 → 산출물은 필수.** 발표에서 말한 주장은 산출물에도 반드시 실려 있어야 한다
- **산출물 → 덱은 선택.** 상세 표·전체 스키마·코드 수준 정의는 덱에 올리지 않는 것이 기본

## 흐름 자가 점검

FLOW.md 를 쓴 뒤 아래를 스스로 검사하고 결과를 사용자에게 보고한다.

- **시간 역행** — 문제 → 결과 → 다시 문제 처럼 되돌아가는 구간이 있는가
- **결과 지연** — 결과·화면이 처음 등장하는 장이 앞 1/3 안에 있는가.
  청중이 "이 서비스가 화면에서 뭘 하는지" 모른 채 내부 구조를 듣는 구간이 길면
  뒤의 모든 장이 근거 없는 설명이 된다. 순서는 **문제 → 해결된 모습 → 그게 가능한 이유** 다
- **중복 주장** — 같은 메시지를 두 장이 반복하는가
- **밀도 편차** — 모든 장의 정보량이 비슷하면 강조점이 없다. 의도적으로 가벼운 장을 둔다
- **결론 연결** — 마지막 장의 요청이 앞의 근거로 뒷받침되는가
- **분담 위반** — 산출물이 맡기로 한 주제가 덱에 통째로 들어와 있지 않은가
- **정직성** — `제안`을 `확인됨`처럼 말하는 장이 있는가

## 경계

- FLOW.md 외의 파일을 만들지 않는다. 대본·HTML·PDF 는 이 스킬의 범위가 아니다.
- 배열을 제시한 뒤 **멈추고 사용자의 판단을 기다린다.** 승인 없이 다음 단계로 가지 않는다.
- 사용자가 흐름을 고치라고 하면 FLOW.md 만 고친다.
