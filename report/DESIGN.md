# 보고서 디자인 규칙

차분한 편집물 톤을 따른다. 따뜻한 미색 종이, 먹색 글자, 명조 제목, 가는 줄, 강조색은 클레이 하나다. 템플릿 `assets/report_template.html`에 아래 규칙이 모두 들어 있으므로 CSS를 새로 짜지 말고 템플릿을 복사해 시작한다.

## 1. 색 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#FAF9F5` | 종이 배경. 그림 배경도 같은 색 |
| `--ink` | `#141413` | 제목, 굵은 글씨, 표 머리 밑줄 |
| `--body` | `#2B2A27` | 본문 |
| `--muted` | `#6B6A64` | 캡션, 라벨, 바닥글 |
| `--rule` | `#DEDCD3` | 표 행 구분선, 바닥글 윗줄 |
| `--card` | `#F0EEE6` | 설명 상자, 인라인 코드 배경 |
| `--clay` | `#D97757` | 유일한 강조색. 번호, 최종안 강조, 상자 제목 |
| `--clay-soft` | `#F5E3DA` | 표의 최종안 행 배경 |

강조색을 둘 이상 쓰지 않는다. 그림에서 세 번째 계열이 꼭 필요할 때만 올리브 `#788C5D`를 쓴다.

## 2. 글꼴

| 역할 | 글꼴 | 크기 |
|---|---|---|
| 표지 제목 `h1` | Nanum Myeongjo ExtraBold | 34pt, 두 줄 이내, `white-space: nowrap` |
| 쪽 제목 `h2` | Nanum Myeongjo ExtraBold | 20pt |
| 큰 숫자 `.stat .val` | Nanum Myeongjo ExtraBold | 30pt |
| 본문 | Apple SD Gothic Neo | 9.6pt, 줄간격 1.62 |
| 라벨·kicker | Apple SD Gothic Neo, 대문자 자간 0.12~0.16em | 7.4~7.6pt |
| 숫자 열·코드·파일명 | SF Mono / Menlo | 8~8.4pt |

명조는 제목과 큰 숫자에만 쓴다. 한글 본문은 고딕이 읽기 쉽다. 외부 웹폰트에 의존하지 않고 렌더링하는 컴퓨터에 설치된 글꼴을 쓴다. 표의 글꼴이 없으면 `:root`의 `--serif`, `--sans`, `--mono`만 설치된 명조 · 고딕 · 고정폭 글꼴로 바꾼다.

## 3. 페이지 구조

- `@page { size: A4; margin: 0 }`이고, 한 쪽은 `<section class="page">` 하나다. 크기는 210×297mm로 고정되고 안쪽 여백은 19/18/20mm다.
- 쪽 하단에는 `.foot`(보고서 짧은 제목 + 두 자리 쪽 번호)를 둔다. 본문은 바닥글 윗선 4mm 위에서 끝나야 한다.
- 쪽마다 같은 순서로 쌓는다. kicker(`<b>번호</b> 장 이름`) → `h2` 결론을 명사형으로 끝낸 제목 → `.lede` 리드 두 문장 이내 → 본문.
- 한 쪽에는 메시지 하나만 둔다. 그림 하나와 표 하나가 기본이고, 그림 두 장이면 표는 짧게 쓴다.
- 쪽이 넘치면 이 순서로 고친다. ① 문장 압축 ② 그림 폭 86~90%로 축소 ③ 표 열 폭 조정 ④ 쪽 나누기. 글자 크기는 줄이지 않는다.
- 표지 구성: 날짜 라벨 → 명조 제목 → 얇은 곡선(SVG) → 부제 → 번호 목차(가는 줄 리더 + 쪽 번호) → 메타 행(라벨 + 모노 값).

## 4. 컴포넌트

| 컴포넌트 | 클래스 | 쓰는 곳 |
|---|---|---|
| 숫자 카드 3개 | `.grid3 > .stat` | 요약 쪽의 핵심 지표 |
| 핵심 메시지 3칸 | `.msg > div` | 요약 쪽 결론. `(1)` 번호는 자동 |
| 소제목 | `h3 > .n` | `A`, `B`, `C` 순번을 클레이 모노로 |
| 표 | `table`, 숫자 열 `.num`, 강조 행 `tr.hl` | 머리 아래 먹색 밑줄, 행 사이 가는 줄. 세로줄 없음 |
| 설명 상자 | `.note > .t + p` | 추가 설명이 필요한 곳만. 쪽당 1~2개 |
| 2단 | `.grid2` | 짧은 표 두 개, 상자 두 개 |
| 그림 | `figure > img + figcaption > b` | 캡션은 `그림 N` + 결론 한 문장 |
| 코드 | `pre`, 주석은 `span.c` | 먹색 배경 블록. 재현 쪽에만 |

## 5. 줄바꿈 규칙

1. 전역 `word-break: keep-all`로 한글 단어 중간에서 끊지 않는다.
2. `p`, `figcaption`, `.msg div`, `.stat .sub`에는 `text-wrap: pretty`를 적용한다. 마지막 줄이 너무 짧아지지 않는다.
3. `h1`, `h2`, `.lede`, `td`, `li`, `.bal`에는 `text-wrap: balance`를 적용한다. 줄 길이가 고르게 나뉜다. 두 줄짜리 짧은 문단에는 `class="bal"`을 붙인다.
4. 갈라지면 안 되는 묶음은 `<span class="nw">…</span>`로 감싼다. 자주 나오는 경우는 이렇다.
   - 괄호와 그 앞 단어: `(Target_2)를`, `(−0.011, −0.004)`
   - 숫자와 단위·명사: `평일 수`, `3일 변화`, `평가 200일`, `한 fold`
   - 식과 비율: `오늘 값 − 3일 전 값`, `0.5 : 0.5`
   - 가운뎃점 목록: `전날·당일·다음날`, `유가·금리·원자재`
   - 고유한 구: `코로나 급락·반등`, `요일 프로파일`
5. 문장이 계속 어색하게 끊기면 `nw`를 늘리지 말고 문장을 다시 쓴다. 예: 따옴표 질문 두 개를 나열한 문장 → "A(Target_1)와 B(Target_2)가 3일 뒤 오를 확률을 예측했습니다".
6. `report_tool.py check --breaks`의 줄바꿈 목록을 끝까지 읽고 판단한다. 짧은 꼬리 줄 0건만으로는 충분하지 않다. 단어 묶음이 갈라지는 것은 길이로 잡히지 않는다.

## 6. 그림

- `assets/mpl_style.py`의 스타일을 쓴다. 그림 배경을 종이색으로 맞추고, 제목은 왼쪽 정렬 굵게, 위·오른쪽 축선은 없앤다.
- 기본 막대는 먹색 `#3D3D3A`, 최종안이나 두 번째 계열은 클레이 `#D97757`, 기준선(0.5 등)은 회색 점선 `#C2C0B6`이다.
- 막대 끝에 값을 적고 범례는 선과 겹치지 않는 빈 곳에 둔다(`loc="lower left"` 등). 저장 후 반드시 이미지를 열어 겹침을 확인한다.
- 그림 폭은 본문 폭 100%가 기본이다. 넘침을 막을 때만 `style="width:86%;margin:auto"`로 줄인다.
- 강조색은 그 그림의 메시지가 가리키는 막대에 쓴다. "보충일이 낮다"가 메시지면 보충일 막대가 클레이다. 메시지와 반대쪽을 강조하면 눈이 엉뚱한 곳으로 간다.
- 발표 덱에서도 쓸 그림이면 제목을 지운 판본을 `figures/deck/`에 한 벌 더 저장한다. 덱은 슬라이드 제목이 결론을 말하므로 그림 제목이 겹친다. 배경색이 덱과 같아 그대로 붙는다.

## 7. 하지 않을 것

- 쪽 경계에 의존하는 흐름 문서(`page-break-*`만 쓰는 방식)로 되돌리지 않는다. 제목과 본문이 갈라진다.
- 굵은 세로줄 표, 배경색 표 머리, 그림자, 둥근 카드 남발, 파랑·초록 같은 추가 강조색.
- 글자 크기를 줄여 쪽에 욱여넣기.
